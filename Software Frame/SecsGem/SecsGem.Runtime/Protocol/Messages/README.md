# 指令格式备注索引

当前全部 **39 个已注册指令处理器**的类备注均包含具体值的 SML 示例，并在字段右侧写明名称/含义；有应答的事务一并列出应答。示例放在 XML 文档的 `code/CDATA` 内，代码中直接显示 `<L ...>`，不需要阅读 `&lt;` 转义文本。

## 阅读约定

```sml
'S7F1'W                    // Host→设备，W=1，请求应答
<L [2]                     // 两个直接子项
    <A [9] 'DEMO-FAST'>     // PPID：ASCII 配方编号
    <U4 [1] 62>            // LENGTH：配方正文 62 字节；这里是一个 U4 元素
>
.
'S7F2'                     // 设备→Host，应答不置 W
<B [1] 0x00>               // PPGNT：0=允许下载
.
```

- 行末 `//` 是阅读说明，**不是线上字段**；复制到模拟器前去掉说明。不同工具的 SML 导入语法可能不同。
- `L[n]`：直接子项数量，不是总字节数或所有层的叶子数。
- `A[n]`：本例 ASCII 数据长度；引号不属于数据。
- `B[n]`：二进制字节数量；`0x00` 是十六进制字节。
- `U4[1]`：一个四字节无符号整数，不是一个字节，也不是四个元素。其他数值类型的 `[n]` 同样是元素数量。
- 标题末尾 `W`：请求应答；省略表示 W=0。`.` 结束一条 SML 消息。
- 无正文与 `L[0]` 不相同：例如 S7F19 必须无正文，而 S7F17 的 L[0] 会删除全部配方。
- 示例 ID、型号、名称、值及成功应答只是明确的场景假设；须替换现场配置，不能据此推断固定参数数量或固定业务模型。
- 报文示例不包含 HSMS 四字节长度前缀、十字节外层报头或真实 System Bytes。S9 的 B[10] 是正文中携带的**原消息**报头，不是本次 S9 外层报头。

## 实现与标准的边界

备注按当前实际组包编写，不把期望结构伪装成已经实现：例如 S5F1 现有额外 L[1] 包装、S1F12 使用 ASCII ID 和 DataTypeName、S5F3 将 1 解释为启用、S6F11 使用 ASCII DATAID 和 U2 CEID/RPTID，均已在对应类备注说明。此举不是对这些差异的标准符合性背书，也不修改它们的业务逻辑。

涉及 S2F15 写常量、S2F31 设置 Windows 系统时间、S2F33/F35 保存配置、S2F41 远程命令、S7F17 删除等有副作用的指令，不因文档示例而自动运行。
