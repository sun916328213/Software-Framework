# 模型与匹配能力（P5）

最新大图预算修复：原图全角计划超预算且模板可安全降采样时，先复用降采样/局部定位，不执行或计费该全图计划；真正执行阶段仍累计受1亿响应像素限制。1920×1080、96×64模板的17.3度靠边/居中案例红绿通过；本轮715逻辑/26定向WPF通过，隔离宿主构建成功。默认目录被运行中的工作台/VS锁文件，须关闭旧进程并重新生成再启动；尚未拿到用户原图复核。详见验证记录。

## 当前：OpenCV有界离散旋转/等比尺度搜索与漏检精化

OpenCV/TemplateMatch在原DTO增加AngleStartDeg、AngleExtentDeg、AngleStepDeg、ScaleMin、ScaleMax、ScaleStep及MaxOverlap；旧配置缺字段默认为0角度/1倍，继续执行原固定方向算法与原邻域抑制。姿态路径只接受Mono8，逐采样生成变换模板并排除补边，三种归一化方法经当前OpenCV4.11部署二进制的独立合成图执行；返回中心、实际离散角度/Scale、变换矩形四角及轴对齐外接框，显示与拾取使用实际四角。正角度遵守Pose2D（图像坐标中视觉上顺时针）。原结果表/定位候选传递真实姿态；下游继续拒绝非单位Scale，不暗称已实现缩放跟随。

新建Controls目录工具默认-180°/360°搜索范围，Raw DTO与旧配置仍保留0°/零范围；旧节点必须显式设置范围才能搜索旋转。原离散搜索不足额或截断不安全时，补降采样位置提议、合并重叠局部窗、原图0.5°角度提议及0.1°采样；仍用原方法和MinScore最终评分，保留已有有效目标。有足额离散解时沿原粗步长结果；0.1°是局部采样间隔，不是全场连续估计或精度保证。17.3°/-38.2°/179.4°独立逆映射合成大模板从5项全红转绿，范围外拒绝及候选预算继续有测试。最新713逻辑/580WPF全过，宿主64警告/0错误；未提供用户实图，不能据此验收现场召回率与节拍。

**边界**：这是有界离散参考搜索及降采样/局部回退，不是完整形状金字塔、连续角度估计或亚像素算法；三种方法分数和HALCON分数不等价。最大1024姿态组合、1亿响应像素、100目标；候选超过安全预算且可能影响最终结果时明确失败；精度受步长和插值限制。单次Native计算不可中断，后台快照隔离及会话关闭等待实际结束。补边排除是内部算法有效区，不是用户模板掩膜；目前无用户掩膜/任意原点、搜索ROI、部分出界匹配或硬实时保证。见[扩展计划V3](TOOL_EXPANSION_PLAN.md)。

## 两类匹配

| 项目 | OpenCV/TemplateMatch | HALCON/ShapeMatch |
|---|---|---|
| 准备 | Mono8轴对齐矩形取样；原像素复制，不改搜索输入 | Mono8取样；独立训练参数与显式训练，旧模型在取样/训练设置改变后不可当新模型运行 |
| 模型 | `.vtemplate`保存取样；无需训练，不提供假的训练成功 | `.vshape`包保存原生模型/可选取样/训练范围；兼容`.shm`，后者可能没有取样，不伪造训练图 |
| 搜索 | 旧默认固定姿态；可配置离散角度/正等比Scale及最大重叠；SqDiffNormed/CCoeffNormed/CCorrNormed | 原scaled shape model算子；角度/尺度搜索、分数、候选数、重叠/贪婪度受原工具参数与训练范围限制 |
| 结果 | 中心、分数、实际离散角度/尺度；姿态路径另提供旋转四角及轴对齐外接框 | 原参考位置、角度、尺度、分数；参考点遵循模型原点，不臆造外接框/搜索图轮廓 |
| 定位消费 | 显式选择0起候选索引和基准；同输入仅单位尺度刚体，非单位尺度明确拒绝 | 同一IFixtureResult契约保留真实角度/Scale；P3拒绝非单位Scale，不能把支持缩放匹配当作下游已支持缩放跟随 |
| 当前证据 | 实际模型保存/清除/加载、双候选分数排序、选第二候选、图像平移、原.flow重开、Blob面积/位置与坏文件回归；离线合成图，不泛化实图精度 | 托管取样/训练参数、失效与模型引用契约；P3原结果消费有旋转测试。真实训练/模型文件/匹配用例仍RequiresRuntime，未验收 |

新增的是离散灰度旋转/等比缩放搜索，不新增隐式图像坐标链或用户模板掩膜。训练取样和搜索输入不是同一个记录；HALCON世界/机台单位不能直接画到图像。两个后端分数含义与阈值不承诺相同。

## 模型文件与任务

- 模型由原ITemplateTool与TemplateModelFile读写，任务沿用原`.flow`节点配置。任务保存取样/训练参数与外部文件引用，不保存运行结果、原生句柄或已加载AI会话。
- 成功重新取样、训练、标脏训练或清除后撤销旧ModelReferencePath；不会删除用户保存的模型文件。成功保存/加载后记录对应路径并通知UI，失败/取消保留原模型引用。文件引用只是路径提示，不是已验证的资源包或内容哈希。
- OpenCV任务有内嵌取样即可匹配：重开不读取引用文件，引用缺失时明确提示而不假称未准备或已加载。HALCON的内嵌取样不等于原生模型，必须显式训练/加载；AI同样必须显式加载。
- 模板页显示模型状态与文件引用。原三参构造保留；实际工作区提供只读/忙态谓词，命令与直接Capture均守卫，模态文件选择返回后再检查。UI卸载不释放借用模型。
- 文件路径暂未做相对路径迁移、外部模型打包或去重。移动工程/模型后须确认提示并显式选择，不能宣传为自包含SDK部署包。

## AI工具与Provider

四类工具仍使用原AIToolBase与IAIProvider：分类为类别/分数，检测为真实框，分割为Provider实际提供的轮廓/掩膜/区域信息，异常检测为异常分数/标志/可选定位。没有位置就不补造；加载推理模型不叫训练。

| Provider | 声明任务 | 当前显式设备选择 | 实际验收边界 |
|---|---|---|---|
| Halcon | 分类、检测、分割、异常检测 | 空值默认，或`cpu`（不区分大小写）；其它非空值明确拒绝 | 实际DL模型/预处理、Runtime、License及CPU/GPU部署仍须授权验证，声明能力不是成功推理证据 |
| Aiditron | 分类、检测、分割；无异常检测声明 | 只接受默认（留空）；适配尚无显式设备选择，不能忽略cpu/gpu0等请求 | 需要实际SDK/DLL/模型；Legacy无显式单工程卸载API，不能承诺超出厂商接口的释放或取消能力 |
| Invi | 分类、检测、分割；无异常检测声明 | 只接受默认（留空）；其它非空值明确拒绝，拒绝发生在native manager创建前 | fake native已有契约/失败清理证据，真实SDK/DLL/模型及设备配置仍待验收 |

本轮兼容性说明：此前被悄悄忽略的非默认设备字符串现在报错；参数名/格式不变，默认设备行为保留。不要通过清空设备标识伪装“已按指定GPU执行”。fake Provider可声明测试设备，这不表示三个实际Provider已支持该设备。

| 生命周期对象 | 拥有者/借用者 | 准备、失效与释放 |
|---|---|---|
| 取样与匹配原生模型 | 原工具拥有；模板VM/画布借用 | 显式取样/训练/加载；工作区关闭等实际调用结束，再由工具释放 |
| AI会话 | AIToolBase记录打开它的Provider | 显式EnsureLoaded/LoadModel；路径、设备、Provider变化不能沿用旧会话；重新加载先卸载；关闭按原Owner回收 |
| 结果/结果表 | 原ToolCardWorkspace拥有 | 输入/参数/模型变更使旧结果失效；坏模型加载后撤下原结果及依赖定位结果；视图不二次释放 |
| Provider | 创建它的Workspace/宿主 | 不由借用编辑器释放；部分失败与关闭按原所有权策略处理 |

P5新WPF契约覆盖四任务×路径/设备两种变更：未加载Run失败且不OpenSession，显式加载后成功，变更后再次失败且不隐式加载；`.flow`重开仍未加载，显式加载后可运行；3个fake会话对应3次关闭。它们不是实际模型推理/性能或精度验收，也没有承诺原生SDK可立即取消。
