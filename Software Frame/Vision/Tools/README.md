输入为独立 Core 快照，SDK 图像由算法边界复制并拥有；行尾 padding 不参与像素运算。结果只返回可独立读取的 Core 数据，不携带原生句柄。

每上下文一个当前模型，准备成功原子替换，失败保原模型。公开 GUID 不是模型存活凭据。未知模型定义即使伪装已有种类，也不能进入后端。

取消等待不代表 SDK 停止。关闭等待真实执行结束，再释放模型/后端；迟到结果不发布，清理失败保留资源供重试。每次 ValueTask 返回值仅消费一次。

## T1 第一批行为

- 阈值/统计接收 SearchRegion 的不可变几何快照，并复用 Core 像素中心和矩形半开边界规则；原始 ROI 后续编辑不影响请求。
- 阈值域外始终为0，统计域外不参与；有效域内没有命中仍是成功，空参与域则拒绝。
- 整数裁剪构造器拒绝越界，不隐式缩放或转换位深；显式 `FromClippedBounds` 才对有限浮点矩形先求视野交集再向外取整，无交集拒绝。ImageCropOutput.ImageToSource 只映射到直接输入图像，多次裁剪需逐级组合，不猜世界坐标或跨分支来源。
- VisionImageOperation 强制图像输入；无图请求留在 VisionOperation，不把假图或空图交给 SDK。具体数值工具已在 T2 首批接通。
- 本轮 OpenCV 使用内存合成图验证；HALCON 的新原生实现仅完成编译，裁剪路由/来源核验使用 SDK 边界 fake，未执行新的原生算法验收。

## T1 第二批：文件、格式与灰度数值

- 文件输入要求绝对路径，读取一次编码内容快照后交给所选OpenCV解码器；SHA256来自同一快照。每次读取创建独立帧/空间，不从文件名推断帧等价或标定。
- ImDecode(Unchanged)保留实际位深/通道，颜色明确为BGR/BGRA，16位多通道等Core未定义格式明确拒绝。只交付解码器主图，不自动EXIF旋转或遍历动画/多页。
- 编码读取上限64MiB；这是读取预算，不是解码器原生内存分配的硬隔离保证。
- 格式转换支持：RGB/BGR互换、RGB/BGR/BGRA转Mono8、显式增删alpha、Mono8复制到颜色通道，以及Mono8无缩放扩大为Mono16。BGRA移除alpha不与背景合成。
- Mono16到Mono8必须显式使用GrayLinearOperation的gain/offset；不按本幅图极值自动归一化。线性计算先用double，再按输出位深限幅并进行SDK最近整数舍入。
- 转换创建新帧但保持像素尺寸和坐标空间；解码/转换结果会经过统一引擎来源、格式和尺寸核验。损坏/缺失文件失败不带旧结果。
- 新功能当前仅由OpenCV声明。HALCON不借用OpenCV补缺，明确返回Unsupported；未加载AI模型或运行宿主。

## T1 第三批：邻域算法边界

- 基础滤波核为奇数3..99。高斯sigma必须明确给出，支持0.01..1000像素，非高斯不接受无效sigma；均值/高斯支持补零、复制和Reflect101，中值仅复制边界，Mono16核仅3/5。
- Otsu在原始8/16位直方图上选择阈值，不先降为8位。普通模式pixel>阈值为255，反向模式pixel≤阈值为255，返回本次实际阈值。
- 局部阈值仅Mono8，窗口为奇数3..255，整数Offset为-255..255；按局部均值或高斯统计与偏移计算，邻域统计有整数舍入，复制边界。不是全局阈值的别名。
- 形态学只接受0/255二值Mono8，不自动阈值化灰度图。矩形/椭圆/十字核的宽高为奇数1..99，中心锚点，Iterations为1..20；开/闭表示各基础阶段次数。补零边界显式为0，不借用SDK腐蚀时的特殊默认值。
- 本批操作均为全图。需要局部窗口可先显式裁剪并保留映射；没有ROI参数就不声称滤波/形态学会保持原ROI外区域。输出不改像素位置，创建新帧但保持尺寸/空间，全黑输出仍为Success。
- 新能力当前仅接OpenCV。HALCON不自动切换到OpenCV，也未完成新的原生验证。
- T1基础交付验证：本批12项新案例通过；与文件/转换、ROI/裁剪和必要旧路径合并定向29项通过，0失败、0跳过。必要模块构建均0警告、0错误，未跑全量或宿主。详细日志与证据边界见总体计划第13节。
